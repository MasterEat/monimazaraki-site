# Ιερά Μονή Μαζαρακίου — Stitch reference package

Το πακέτο περιέχει τις επιλεγμένες σχεδιαστικές αναφορές από το Google Stitch.

- Το κεντρικό `index.html` λειτουργεί ως κατάλογος προεπισκόπησης.
- Κάθε φάκελος μέσα στο `screens/` έχει δικό του `index.html` και ανοίγει απευθείας στο GitHub Pages.
- Τα μεγάλα `screen.png` αφαιρέθηκαν για να μειωθεί σημαντικά το μέγεθος του repository.
- Οι σελίδες είναι ακόμη ανεξάρτητα mockups. Η τελική responsive ιστοσελίδα θα ενοποιηθεί αργότερα με Codex.
