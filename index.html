Ιερά Μονή Αγίου Ιωάννου του Θεολόγου Μαζαρακίου

Κεντρική σελίδα προεπισκόπησης των επιλεγμένων σχεδίων του Google Stitch.

Τα παρακάτω είναι ξεχωριστές σχεδιαστικές αναφορές και όχι ακόμη η τελική ενιαία ιστοσελίδα. Τα αρχεία έχουν μετονομαστεί σε index.html, ώστε κάθε φάκελος να ανοίγει απευθείας μέσω GitHub Pages.
