# Ιερά Μονή Μαζαρακίου — Επιλεγμένες αναφορές Stitch

Το πακέτο περιλαμβάνει μόνο τα screens που θα χρησιμοποιηθούν ως οπτικές αναφορές για την τελική υλοποίηση.

## Αντιστοίχιση

1. `01-home-desktop` — τελική κατεύθυνση αρχικής (`updated_1`)
2. `02-programme-desktop` — πρόγραμμα ακολουθιών (`updated_2`)
3. `03-news-archive-desktop` — αρχείο νέων (`corrected`)
4. `04-monastery-history-desktop` — Η Μονή (`_5`)
5. `05-monastic-life-desktop` — Μοναχική Ζωή (`_4`)
6. `06-ministries-desktop` — Διακονήματα (`_7`)
7. `07-single-article-desktop` — μεμονωμένο άρθρο (`_6`)
8. `08-visit-desktop` — Επίσκεψη (`_8`)
9. `09-contact-desktop` — Επικοινωνία (`_9`)
10. `10-home-mobile-reference` — mobile αισθητική αρχικής (`mobile_corrected_2`)
11. `11-programme-mobile-reference` — mobile διάταξη προγράμματος (`mobile_corrected_1`)

## Σημαντικό

Τα HTML αρχεία είναι σχεδιαστικά mockups και όχι τελικός κώδικας παραγωγής. Η τελική υλοποίηση πρέπει να γίνει ως ένα ενιαίο responsive project με κοινά header/footer/components.
